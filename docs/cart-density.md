# Cart density preference

The user prefers compact, easy-to-scan operational pages. Apply this direction to future page changes when requested; only the cart is updated now.

The user requested an even thinner second pass. The cart uses 7px vertical / 10px horizontal row padding, 5px between rows, 14px item titles, and 12px metadata. Equal-width Borrow/Consume buttons stretch across the remaining space beside side-by-side Edit/Remove controls, sharing one line below the metadata with 26–28px controls. Thinning means reducing height, not width. Preserve readable names, wrapping, selected states, keyboard focus, and existing theme colors. Avoid excess vertical padding when extending this style.
